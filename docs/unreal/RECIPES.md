# RECIPES: the common tasks, with their answers

GENERATED by `tools/tests/recipes_gen.py`: each command below was run through the generated CLI against the
fake engine and its `--json` answer is shown under it (lists cut to 3 items). On a box the values differ
(positions, timings, paths); the shapes and the codes do not. Start with [GUIDE.md](GUIDE.md); the tools are
in [dx.md](dx.md).

## 2. Start a clean level

Everything below happens in it.

```bash
film-ue level new --path /Game/Recipes/L_Recipes --json
```
```json
{
 "ok": true,
 "op": "level.new",
 "result": "/Game/Recipes/L_Recipes",
 "stdout": ""
}
```

Check: `result` is the level path.

## 3. Put basic shapes in the level

A shape converges on its label: running it again replaces, never duplicates.

```bash
film-ue level spawn --label Box --shape cube --loc 0,0,50 --json
```
```json
{
 "ok": true,
 "op": "level.spawn",
 "result": "Box",
 "stdout": ""
}
```

```bash
film-ue level spawn --label Ball --shape sphere --loc 150,0,50 --size 50,50,50 --json
```
```json
{
 "ok": true,
 "op": "level.spawn",
 "result": "Ball",
 "stdout": ""
}
```

Check: `result` is the label.

## 5. Move and aim an actor

```bash

  -100.0,
  50.0
 ],
 "stdout": ""
}
```

## 17. A typo, caught before anything is sent

Exit code 2: nothing reached the editor.

```bash
film-ue level move --lable Box --json     # exit 2
```
```json

 "op": "level move",
 "error": {
  "code": "bad_args",

   "--label",
   "--scale",
   "--live"
  ]
 }
}
```

Check: `error.candidates` holds the fix.
