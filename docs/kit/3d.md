# The 3D kit (`@kit/3d`)

3D blocks for film.ts: each is a Scene configured entirely by `params`, rendered on the engine's Stage (dim studio,
depth of field, rotated-grid supersampling), deterministic in time, framed for the film's live aspect (landscape,
vertical, square). Galleries: `films/gallery-3d` (landscape), `films/gallery-3d-vertical`.

```ts
import { defineFilm } from '@engine/film';
import { Hero3D, Panel3D, GlyphCloud, Logo3D, Cards3D } from '@kit/3d';

export default defineFilm({
  id: 'launch', format: 'landscape', theme: 'midnight', audio: { bpm: 110 },
  vo: [{ text: 'Made in code, lit like a studio.', start: 4.9, end: 7.0 }],
  scenes: [
    { id: 'hero', scene: Hero3D, length: { bars: 2 }, params: { text: 'Launch films,\nbuilt in 3D.', emphasis: ['3D.'], sync: 'beats', reveal: 'slam', exit: 'blow', whip: 'left' } },
    { id: 'voice', scene: Hero3D, length: { bars: 2 }, transition: { kind: 'whip', dir: [-1, 0] }, params: { text: 'Made in code,\nlit like a studio.', sync: 'vo', reveal: 'tip', camera: 'orbit' } },
    { id: 'term', scene: Panel3D, length: { bars: 2 }, transition: 'xfade', params: { panel: { kind: 'terminal', rows: 5, type: 0.3, lines: [{ text: '$ bun test', kind: 'cmd' }, { text: '✔ 412 pass', kind: 'out' }] } } },
    { id: 'cloud', scene: GlyphCloud, length: { bars: 2 }, params: { resolve: '60 fps', resolveAt: { beat: 3 } } },
    { id: 'logo', scene: Logo3D, length: { bars: 2 }, transition: 'dip', params: { tagline: 'Launch films, written in code.' } },
  ],
});
```

## Common params (Scene3D, `kit/3d/scene3d.ts`)

| param | default | |
|---|---|---|
| `background` | `'theme'` | `'theme'`, a role, `#hex`, `{ from, to, angle }`, or `'none'`: transparent, for an overlay or stacking (alpha is the sharp render's coverage; a defocused edge keeps its sharp silhouette's alpha) |
| `spot`, `spotAt` | `0.35`, `[0.5, 0.45]` | a soft lift of the backdrop toward `surface` behind the subject |
| `camera` | per block | `'static' \| 'push' \| 'pull' \| 'orbit' \| 'drift' \| 'dolly' \| 'crane'`, or keys `[{ t, pos, target, fov?, roll?, ease? }]` (t: s from the shot start, block world units) |
| `cameraAmount`, `cameraEase`, `drift` | `1`, per move, `true` | scale of the move; a util.ts ease name; the slow drift under named moves |
| `az`, `el`, `fov` | per block | framing angle (degrees) and lens |
| `whip` | — | `'left' \| 'right' \| 'up' \| 'down'`: a 110 ms whip out on the cut (pair with a `whip` transition) |
| `dof`, `fstop`, `focus`, `maxBlur` | `true`, per block, `'auto'`, `40` | focus `'auto'` follows the block's subject; a number is a world distance |
| `key`, `rim`, `fill`, `softbox`, `env` | `1` | the light rig's levels (multiples of the house rig); `keyColor`, `rimColor` (role or #hex, default `fg`: neutral) |
| `glow` | `3` | accent emissive level (look.ts); `0` turns glow off |
| `exit`, `exitDur` | `'none'`, `0.4` | `'fade' \| 'rise' \| 'sink'` (blocks add their own) |

Times are TimeRefs (`1.2`, `{ beat: 4 }`, `{ bar: 1 }`) from the shot start, as in the 2D kit.

## Blocks

**Hero3D** — extruded headline (Type3D, satin fg; emphasis words in an accent with a glowing seam).
`text | lines` (strings or `{ text, at?, emphasis? }`), `size 210` (px em), `maxWidth`, `role/width/weight`, `tracking`,
`leading`, `align`, `depth 0.16`, `bevel 0.012`, `emphasis`, `emphasisColor 'accent'|'accent2'`,
`reveal 'slam'|'rise'|'tip'|'drop'|'scale'`, `unit 'word'|'glyph'|'line'`, `stagger`, `cascade`,
`sync 'stagger'|'beats'|'vo'`, `every`, `delay`, `sweep true|false|TimeRef[]` (glint across the faces),
`pulse 0.35` (accent seams swell on beats), `exit 'fall'|'blow'|'scatter'|'fade'|'rise'|'sink'`, `seed`.
Defaults: camera `push`, az −18, el 5, fov 26, fstop 2.8.

**Panel3D** — floating UI panels (engine/panels.ts) typing in. `panels` (or `panel`): PanelInput with `w` (default
1100), `rows` or `h`, `lines` whose `at` is a TimeRef; per panel `type` (TimeRef: untimed lines type in one after
another at `cps` 42), `enter` (when it rises in). `layout 'single'|'pair'|'stack'|'fan'` (a pair stacks in a tall
frame), `tilt 14`, `highlight { panel, line, at, color }` (a blade of light under the line, a lit bar, a wash).
Focus pulls to the panel that is active. Defaults: camera `push`, az −4, fov 30, fstop 2.4.

**GlyphCloud** — a seeded field of SDF glyphs flowing past the camera, accent sparks twinkling on the beat, resolving
into a word. `count 1400`, `seed`, `chars`, `size 30`, `depth 9`, `flow 0.45`, `sparkle 0.035`, `sparkleColor`,
`resolve`, `resolveAt { beat: 4 }`, `resolveSize 170`, `resolveColor 'fg'`, `resolveStagger`, `weight`.
Defaults: camera `push` (amount 1.4), fov 34, fstop 2.0.

**Logo3D** — the film's SVG (`logo`, default `assets/logo.svg`) extruded with a bevel: neutral paths in satin fg,
saturated ones in the accent (`accentStyle 'solid'|'seam'`, `accentColor`); `name` sets a Type3D wordmark when there is
no SVG. `depth 0.18`, `bevel 0.014`, `logoSize 0.34`, `reveal 'spin'|'rise'|'scale'`, `landAt 0.9`, `turntable 0`
(deg/s) or `sway 9`, `tagline`, `taglineAt`, `taglineColor 'fgDim'`, `taglineSize 40`, `pulse 0.3`; a glint on landing.

**Cards3D** — cards (`cards: [{ title?, lines?, lang?, image?, w?, h? }]`: text cards are panels of kind `card`, image
cards a rounded picture from the film's assets) in `layout 'carousel'|'fan'|'stack'|'grid'`, advancing one card
every `every 2` beats from `startAt { beat: 1 }` on a soft spring, `front 0`; the front card is in focus.

## Notes

- Sizes are reference px of a 1080 px short side; framing reads W and H at run time (camera.ts `fitDistance`).
- Pure, tested pieces: `camera.ts` (moves, orbit, fit, whip), `motion3d.ts` (reveal and exit poses), `layout3d.ts`
  (panel and card placements, the beat slot), `logo.ts extrudeShapes`.
- Engine change: `Stage.render(out, { alpha: true })` (opt-in) keeps coverage in alpha for `background: 'none'`.
